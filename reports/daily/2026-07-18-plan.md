## 🔧 Teknik Detaylar

### Steam Web API Endpoint'leri
```
// Kullanıcı bilgileri
ISteamUser/GetPlayerSummaries/v2/

// Oyun listesi
IPlayerService/GetOwnedGames/v1/

// Oyun süreleri
IPlayerService/GetRecentlyPlayedGames/v1/

// Başarımlar
ISteamUserStats/GetPlayerAchievements/v1/
```

### Rate Limiting Stratejisi
- Steam API: 100.000 istek/gün
- Saniyede maksimum 10 istek
- 429 hatası alındığında exponential backoff

### Veri Modeli
```sql
-- Steam oyunları tablosu
CREATE TABLE steam_oyunlari (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    app_id INTEGER UNIQUE NOT NULL,
    oyun_adi TEXT NOT NULL,
    resim_url TEXT,
    toplam_sure INTEGER DEFAULT 0,
    son_oynama TEXT,
    kategori TEXT,
    senkronize_zamani TEXT
);
```
